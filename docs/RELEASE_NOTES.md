# 0.1.0-beta.2: easier installation

> AI-generated.

Extract the ZIP, run Install.cmd, select your Mod Engine 2 config, choose preview or selling. Launch as usual, press F8.

- Price file beside the DLL found automatically.
- Installer registers the DLL, keeps other mods, backs up changes.
- Updates keep settings and custom prices. Uninstall unregisters and moves files to a backup.
- Settings.cmd switches preview/selling without editing the INI.

Keep rules and seller logic unchanged from beta.1: 2 weapons/shields and Ashes, 1 armor/talisman, all
consumables/goods/ammo, equipped copies protected. Exact prices need a table matching your active regulation.

Windows x64, executable 2.7.1.0 / in-game 1.17.1 only. Offline, experimental; back up your save. Menu/Inventory
indicator appearance and on-screen timeout still unverified. No new live sale test for this build; validated by build,
automated price-loading tests and isolated installer tests.
